Ship Awakened to TestFlight from GitHub

A cloud Mac runs the same prep script the MacBook runs, then signs, archives and uploads. Free, because the repo is public. Your MacBook flow keeps working as it is.

Every time

Start a build

GitHub → Actions → Ship to TestFlight → Run workflow → type the build number → Run. Or tell me the number and I run it. About 15–25 minutes, then TestFlight shows it after Apple's processing. The commit gets a build-N tag.

One-time setup, on the MacBook

1Commit the iOS project

The Xcode project only existed on the MacBook. Pull first (the ignore rules changed), then add it:

cd /Volumes/AwakenedDev/repos/awakened-app && git pull origin main && git add ios && git status --short | head -30 && git commit -m "ios: the Xcode project, for the GitHub build" && git push origin main

Pods, the copied web files, build output and user data stay out. If the status shows thousands of files, stop and send me the list.

2Export the distribution certificate

Keychain Access → login → My Certificates → Apple Distribution: … (LK8FVGBQPL), the one that expires Jun 10 2027 (the only one whose private key is on this Mac) → right-click → Export → format .p12 → choose a password → save to the Desktop as awakened-dist.p12. Then:

base64 -i ~/Desktop/awakened-dist.p12 | pbcopy

Paste into the secret IOS_DIST_P12_B64. The password you chose → IOS_DIST_P12_PASSWORD. Then delete the .p12 from the Desktop.

3The provisioning profile

The one Xcode uses is “Awakened App Store Manual”. This lists the installed copies for Awakened with their expiry:

for f in ~/Library/MobileDevice/Provisioning\ Profiles/*.mobileprovision ~/Library/Developer/Xcode/UserData/Provisioning\ Profiles/*.mobileprovision; do [ -f "$f" ] || continue; x="$(security cms -D -i "$f" 2>/dev/null)"; echo "$x" | grep -q com.goallearner.awakened && printf '%s\n  %s  expires %s\n' "$f" "$(echo "$x" | /usr/libexec/PlistBuddy -c 'Print :Name' /dev/stdin)" "$(echo "$x" | /usr/libexec/PlistBuddy -c 'Print :ExpirationDate' /dev/stdin)"; done

Pick the “Awakened App Store Manual” line with the latest expiry (or download it fresh from developer.apple.com → Profiles), then:

base64 -i "PASTE THE FILE PATH HERE" | pbcopy

→ secret IOS_PROFILE_B64.

If a capability is ever added to the App ID, the profile has to be regenerated and this secret replaced.

4An App Store Connect API key

appstoreconnect.apple.com → Users and Access → Integrations → App Store Connect API → Team Keys → + → name GitHub ship, access App Manager → Generate.

CopyInto the secret
Issuer ID (top of the page)ASC_API_ISSUER_ID
Key ID (on the key's row)ASC_API_KEY_ID
Download API Key (offered once), then run the line belowASC_API_KEY_B64
base64 -i ~/Downloads/AuthKey_*.p8 | pbcopy

5Add the six secrets on GitHub

github.com/GoalLearner/awakened-app → Settings → Secrets and variables → Actions → New repository secret, one at a time:

IOS_DIST_P12_B64 · IOS_DIST_P12_PASSWORD · IOS_PROFILE_B64 · ASC_API_KEY_ID · ASC_API_ISSUER_ID · ASC_API_KEY_B64

Secrets never print in logs and are not available to pull requests from other people.
